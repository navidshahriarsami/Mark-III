# MARK III — Investor Summary

## What Is MARK III?

A personal AI operating system that runs on the user's own hardware. Not a chatbot, not a cloud service — a persistent, private intelligence that lives across all the user's devices.

## Problem

Existing AI assistants:
- Reset between sessions (no persistent memory)
- Know nothing about the user (no personalization)
- Require internet (no offline capability)
- Store your data in the cloud (privacy risk)
- Work on one device (no device continuity)

## Solution

MARK III solves all five problems:
- **Persistent:** Full long-term memory via ChromaDB + Obsidian
- **Personalized:** Learns its owner from day one, builds a unique user model
- **Offline:** Qwen 7B runs locally via Ollama, zero internet required for core features
- **Private:** All data on the user's own hardware, no cloud upload
- **Multi-device:** Desktop brain + Mac + iPhone + Watch, seamless handoff

## Current Status

**Phase Identity complete.** Working prototype with:
- Always-on voice interface (no wake word)
- Local LLM (Qwen 7B, 1-3s response)
- 8 live reflex modules (time, weather, system, network, apps, media, presence, device)
- ChromaDB semantic memory (34 seeded architectural memories)
- Obsidian knowledge bridge (indexes documentation vault)
- User identity engine (profile, learning, session summarization)
- Device mesh (Desktop + MacBook live, iPhone next)
- Cross-network connectivity via Tailscale

## Competitive Advantage

1. **Owned intelligence:** User owns their AI, their data, their model
2. **True personalization:** Each installation learns its specific owner
3. **Zero dependency:** No mandatory paid APIs, no cloud lock-in
4. **Infrastructure moat:** MARK Connect relay = proprietary mesh network
